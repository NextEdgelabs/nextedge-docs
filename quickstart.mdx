## Prerequisites

Use Node.js 20.17 or newer, below version 25, and npm.

<Steps>
  <Step title="Install dependencies">
    From the documentation folder, run:

    ```bash
    npm ci
    ```
  </Step>
  <Step title="Start the preview">
    ```bash
    npm run dev
    ```

    Open [localhost:3333](http://localhost:3333). If that port is busy, use the port printed in the terminal.
  </Step>
  <Step title="Make your first change">
    Edit `index.mdx` and save it. The preview updates as you work.
  </Step>
  <Step title="Check your documentation">
    ```bash
    npm run validate
    npm run check:links
    ```
  </Step>
</Steps>

## Project files

| File or folder | Purpose |
| --- | --- |
| `docs.json` | Branding, theme, and navigation |
| `index.mdx` | Handbook starting point |
| `company/` and `onboarding/` | Company guidance and joiner learning paths |
| `delivery/` and `domains/` | Delivery practices and business playbooks |
| `engineering/` | Architecture and technical guidelines |
| `reference/` | Templates, glossary, ownership, and edition history |
| `guides/` | Writing and publishing guidance |
| `logo/` | Light and dark SVG wordmarks |

The [Mintlify CLI documentation](https://www.mintlify.com/docs/cli/install) provides installation and troubleshooting details.
